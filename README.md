# 🏠 TaskRumah - Family Chore Management App

A fun, Duolingo-style web application where parents can assign and monitor household chores for their children.

## Features

- 👨‍👩‍👧‍👦 **Multi-user**: Admin (parents) and Child roles
- 📋 **Task Management**: Daily & one-time tasks with emoji icons  
- 📸 **Photo Proof**: Children submit photo evidence when completing tasks
- ✅ **Approval System**: Parents approve/reject task completions
- ⭐ **Points & Rewards**: Earn points, redeem for rewards
- 🔥 **Streaks**: Daily streak tracking to motivate consistency
- 💬 **Comments**: Per-task comment threads
- 🔔 **Notifications**: In-app notifications for key events

## Tech Stack

- **Frontend**: Angular 17 + TailwindCSS (standalone components)
- **Backend**: ASP.NET Core 8 Web API (C#)
- **Database**: PostgreSQL 16 (Docker)
- **Auth**: JWT tokens with role-based access
- **File Storage**: Local filesystem (wwwroot/uploads)

## Getting Started

### 1. Start the Database

```bash
docker-compose up -d
```

This starts:
- PostgreSQL on port 5432
- pgAdmin on http://localhost:5050 (admin@taskrumah.com / admin123)

### 2. Run the Backend

```bash
cd backend/TaskRumah.API
dotnet run
```

API runs on http://localhost:5000  
Swagger UI: http://localhost:5000/swagger

### 3. Run the Frontend

```bash
cd frontend/taskrumah-web
npm install
npm start
```

App runs on http://localhost:4200

## API Endpoints

| Method | Endpoint | Description |
|--------|----------|-------------|
| POST | /api/auth/login | Login |
| GET | /api/dashboard/admin | Admin dashboard |
| GET | /api/dashboard/child/{id} | Child dashboard |
| GET/POST | /api/tasks | List/create tasks |
| GET/POST | /api/task-assignments | List assignments |
| POST | /api/task-assignments/{id}/submit | Submit task with photo |
| POST | /api/task-assignments/{id}/approve | Approve task |
| POST | /api/task-assignments/{id}/reject | Reject task |
| GET/POST | /api/rewards | List/create rewards |
| POST | /api/rewards/{id}/redeem | Request reward |
| GET | /api/notifications | Get notifications |

## Development Notes

- Database migrations run automatically on app startup
- Seed data is added via EF Core `HasData()` in `AppDbContext`
- Daily task assignments are auto-generated by the background service at midnight
- File uploads stored in `wwwroot/uploads/proofs/`
